# Pretendard Variable

Source: https://github.com/orioncactus/pretendard (release `v1.3.9`)
File: `packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2`

A single Variable font file (all weights via the `wght` axis) rather than a
set of static per-weight files, kept as the one file actually needed —
loaded locally via `next/font/local` (see `apps/web/src/lib/fonts.ts`), never
fetched from a CDN at runtime.
